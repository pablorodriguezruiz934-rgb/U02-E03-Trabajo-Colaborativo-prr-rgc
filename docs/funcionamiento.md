# Guía de funcionamiento

## Objetivo

El proyecto tiene como objetivo desarrollar una aplicación web para gestionar un videoclub.

## Organización del proyecto

- `peliculas/`: archivos relacionados con el listado de películas.
- `formularios/`: archivos relacionados con los formularios.

## Estado actual

Los archivos disponibles representan la estructura inicial del proyecto. Las funciones que no estén implementadas todavía no deben describirse como si ya funcionaran.

## Cómo consultar los archivos

Abrir los archivos HTML con un editor de código para revisar su contenido. Si son páginas HTML que pueden visualizarse directamente, también se pueden abrir con un navegador.

## Flujo de trabajo colaborativo

Cada integrante trabaja en una rama propia. Los cambios se registran mediante commits, se suben a GitHub y se proponen mediante Pull Requests antes de fusionarlos en `main`.
