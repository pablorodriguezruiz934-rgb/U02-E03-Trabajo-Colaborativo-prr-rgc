# Guía de instalación

## Requisitos previos

Para trabajar con el proyecto se necesita:

- Git instalado.
- Una cuenta de GitHub con acceso al repositorio.
- Un navegador web.
- Un editor de código.

## Clonar el repositorio

Para descargar el proyecto por primera vez, ejecutar:

```bash
git clone URL_DEL_REPOSITORIO
```

Sustituir `URL_DEL_REPOSITORIO` por la URL real del repositorio de GitHub.

## Acceder a la carpeta del proyecto

Entrar en la carpeta creada al clonar el repositorio:

```bash
cd NOMBRE_DE_LA_CARPETA
```

Sustituir `NOMBRE_DE_LA_CARPETA` por el nombre real de la carpeta.

## Actualizar el proyecto

Para actualizar la rama principal:

```bash
git switch main
git pull origin main
```

## Comprobación

Comprobar que los archivos del proyecto están presentes y abrirlos con un editor de código.
